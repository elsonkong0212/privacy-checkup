# 個人資安健檢（privacy-checkup）

盤點自己的帳號、比對已公開的外洩資料，產生一份「🔴 立刻 / 🟡 這週 / 🟢 有空」的行動清單。
**全程不讓 AI 看到你的密碼。**

- 查密碼、比對外洩事件全部由程式在你的電腦上完成；AI 只負責把結果寫成白話
- 燈號（🔴🟡🟢）由規則決定、統計數字由程式計算，AI 改不了，所以同一份資料每次跑出來都一樣
- Gmail 寄件者由 AI 和規則自動判斷，你只要確認 AI 拿不準的幾個；看不懂的網站也由 AI 辨認
- AI 看不到密碼、帳號名稱、email；寫說明時連網站名稱都換成代號。但 Gmail 判斷、辨認網站這幾步**看得到一部分你有帳號的網站網域**。
  每一步送出什麼寫在「AI 看得到什麼」，報告裡也會列出這次實際送了什麼
- 明文密碼檔只在硬碟上存在幾秒：程式等你匯出、讀完馬上刪；不想提供密碼也能跑
- AI 可以用 Claude、Codex 或 Gemini，也可以完全不用


## 需要準備

- Python 3.10 以上，Windows、macOS、Linux 都可以（主程式只用 Python 內建套件，不用另外安裝）
- 選用：
  - Gmail 寄件者掃描、接上你自己的 AI 工具、AI 調查員：`pip install -r requirements.txt`
  - AI：Claude Code、Codex 或 Gemini API 金鑰其中一種（見「選擇 AI」）；沒有也能跑

## 快速開始（示範資料）

```powershell
git clone <這個專案的網址>
cd privacy-checkup
python main.py --demo --llm none           # 不使用 AI，全部用規則判斷（什麼都不用裝）
python main.py --demo                      # 使用 AI：自動找你電腦上有的 Claude Code、Codex 或 Gemini 金鑰
python main.py --demo --llm codex          # 指定用 Codex（也可以用 --llm claude、--llm gemini）
```

開頭會印出這次用的是哪一種 AI。報告會寫在 `output/report_demo.md`。
每次執行都會先跑 43 個自我測試，全部通過才開始健檢，所以測試通過就代表你的電腦可以用。

> macOS / Linux 的指令是 `python3`；Windows 打 `python` 沒反應的話改用 `py`。

## 完整流程（用自己的資料）

所有個人資料都放在**專案外面**的「個人資料資料夾」，程式預設只讀這裡：

- Windows：`C:\Users\你的使用者名稱\privacy-checkup-secrets`
- macOS / Linux：`~/privacy-checkup-secrets`

第一次執行時會自動建立，並印出位置。下面提到的 `passwords.csv`、`my_accounts.csv` 這些檔案，都是放在這個資料夾裡。

- 為什麼放在專案外面：不會跟著專案上傳到 GitHub；用 AI 工具（Claude Code、Cursor、Copilot…）打開專案資料夾時，工作區裡也不會有你的明文密碼檔
- 之前用舊版、資料放在 `privacy-checkup/secrets/`：下次執行時會自動搬過去，並印出搬了哪些檔案
- 想放在別的地方：設定環境變數 `PRIVACY_CHECKUP_SECRETS`（不要放在 OneDrive、Google 雲端硬碟這類會自動同步的資料夾）

| 步驟 | 做什麼 | 指令或檔案 | 時間 |

| 0 | 第一次使用：裝套件、Google Cloud 設定 | 見「需要準備」和「Gmail 寄件者掃描」 | 約 20 分鐘，只做一次 |
| 1 | 掃描 Gmail，AI 自動判斷哪些是帳號、還有沒有在用 | `python gmail_scan.py` | 約 5～10 分鐘 |
| 2 | 只確認標 ★ 的列 | `gmail_candidates.csv` | 幾分鐘 |
| 3 | 補上 Gmail 找不到的帳號 | `my_accounts.csv` | 約 10 分鐘 |
| 4 | 跑健檢（1～3 至少做一項；都沒做的話，至少要在這一步匯出密碼） | `python main.py` | 約 5～10 分鐘 |
| 5 | 程式問你的時候才匯出密碼（選用，可以略過） | 存到「下載」資料夾就好 | 2 分鐘 |

**1. 掃描 Gmail** → 步驟見下一節「Gmail 寄件者掃描」，產生 `gmail_candidates.csv`

**2. 確認 ★ 的列**
- 打開 `gmail_candidates.csv`，只看最前面標 ★ 的列，參考 `suggested`、`reason`，在 `still_using` 填 `y` 或 `n`
- 其他列 AI 和規則已經自動填好；看到填錯的直接改


**3. 帳號清單** → 複製 `templates/my_accounts.csv` 到個人資料資料夾
- 補上 Gmail 掃不到的帳號，例如用 Google、Facebook 登入的網站（到 <https://myaccount.google.com/connections> 看）
- 一行一個網站：`domain`（例如 `shopee.tw`）、`still_using`、`note`（備註，不會交給 AI）
- `still_using` 填 `y`（還在用）、`n`（不用了），或 `?`（**不知道是什麼網站**）
- 填 `n` 的，報告會告訴你怎麼刪；填 `?` 的，報告會請 AI 推測那是什麼網站

**4. 跑健檢**

```powershell
python main.py
```

- 不想用 AI：加 `--llm none`
- Gmail 候選清單、帳號清單、密碼這三種來源，有哪些就用哪些；三種都沒有才會停下來

**5. 密碼檢查（選用）：先不要匯出，等程式問你**

匯出的密碼檔是明文，是整個流程最危險的東西，所以程式的做法是讓它只在硬碟上存在幾秒鐘：

1. 跑到密碼檢查時，程式會問要不要現在匯出密碼。選 `y` 之後它就開始等
2. 這時才到瀏覽器匯出，存到「下載」資料夾就好，檔名不用改
   - Chrome：設定 → 自動填入和密碼 → Google 密碼管理工具 → 設定 → 匯出密碼
   - Edge：設定 → 個人資料 → 密碼 → 右上角「⋯」→ 匯出密碼
   - 也支援 Firefox、Bitwarden 匯出的 CSV（選單位置可能因版本略有不同）
3. 檔案一出現，程式就讀取、把每組密碼換成雜湊值、**立刻刪掉檔案**（先蓋掉內容再刪，不經過資源回收筒），
   並印出檔案在硬碟上待了幾秒。之後查外洩、找重複只用雜湊值

其他情況：

- **不想檢查密碼**：問的時候選 `n`，或加 `--no-passwords`。帳號盤點、外洩比對、165 名單照常進行，報告會註明這次沒有檢查密碼。
  密碼有沒有外洩、重複，也可以用瀏覽器內建的檢查（Chrome：Google 密碼管理工具 → 檢查密碼）
- **已經先匯出好**（放在個人資料資料夾的 `passwords.csv`）：照樣能用，程式會提醒它放了多久，讀完問你要不要刪，**請選刪除**
- **以前忘了刪的匯出檔**：每次執行（包括 `--demo`）都會看一下個人資料資料夾、「下載」和桌面，
  發現密碼匯出檔就列出來、告訴你放了幾天，並問要不要刪。判斷方式是只看檔案第一行的欄位名稱，不會讀到密碼
- 存到會自動同步的資料夾（OneDrive、Dropbox、iCloud…）時會提醒你：檔案可能幾秒內就被上傳到雲端
- 刪除不等於從硬碟上抹掉（SSD 尤其如此）。能做到的是讓檔案只存在幾秒，來不及被同步、備份或被其他程式讀到；
  想要更完整的保護，請開啟整顆硬碟加密（Windows 的 BitLocker、Mac 的 FileVault）

**6. 看報告** → `output/report.md`
- 🔴 立刻處理、🟡 這週處理、🟢 有空再處理：每一項都寫了要做什麼、為什麼、依據是什麼
- 燈號是規則判斷的，AI 只把說明改寫成白話、不能調整燈號；總結開頭的統計數字也是程式算的，AI 只寫「先做什麼」
- 疑似仿冒的網站：你的帳號裡，名稱很像 165 店家官方網站、但其實不是同一個的（例如 `shopee-tw-service.com`）。
  AI 判斷是仿冒的會列成 🔴，提醒你到真正的官方網站改密碼
- ❓ 看不懂的網站：你標 `?` 的網站，AI 推測是什麼、怎麼刪
- 想確認 AI 沒看到密碼：打開 `audit.log`，搜尋你的任何一組密碼，應該找不到

**7. 處理完之後：更新報告**

報告上的項目分兩種，處理完之後的做法不一樣：

- **密碼的問題（編號 P、R、W）**：換完密碼後重新匯出密碼檔、再跑一次 `python main.py`。程式會重新檢查，處理好的就不會再出現
- **其他項目（外洩事件、兩步驟驗證、刪除帳號、165 賣場…）**：程式沒辦法知道你處理了沒。
  例如外洩事件是已經發生的事，換完密碼重跑還是會出現，所以要自己標記：

```powershell
python main.py --done B1 T2    # 把最近一次報告裡的 B1、T2 標記成已處理（不會執行健檢）
python main.py --undo B1       # 標錯了，取消
```

- 標記過的項目下次執行時不列入燈號，改列在報告的「你標記為已處理的項目」，不會憑空消失
- 每次執行，報告都有一節「和上次比」：哪些解決了、哪些是新出現的、哪些還沒處理
- 編號（B1、T2）以最近一次的報告為準；帳號增減後編號可能會變，但程式內部是用「種類＋網站＋事件名稱」記的，不會認錯
- 示範資料要加 `--demo`，例如 `python main.py --demo --done B1`
- 這些紀錄存在 `data/` 資料夾（只在你的電腦上，不會交給 AI）

重新掃描 Gmail 時，你填過的答案都會保留。

**165 高風險賣場名單**會自動抓取，不用做任何事：
  - 店名（例如「蝦皮購物」）要先對應到網域（`shopee.tw`）才能比對。專案內附一張檢查過的對照表 `resources/shop_domains.json`，
    所以**不用 AI 也能比對**，每個人的結果也一樣；表上沒有的新店名才請 AI 翻譯，AI 只看到公開的店名
  - 和你的帳號比對在你的電腦上做，**這一步不會把你的帳號清單交給 AI**（其他步驟會送出哪些網域，見「AI 看得到什麼」）
  - AI 新翻的結果存在 `data/cache/shop_domains.json`，之後只翻新增的店名
  - 對照表是 AI 翻譯後再檢查過的，仍然可能有錯，所以用到它的項目在報告裡都標「請自己確認」，最多只列 🟡
  - 仿冒網域偵測：程式先在本機找出名稱很像這些官方網域的帳號網站，**只有這些可疑的網址**才交給 AI 判斷是官方分站還是仿冒。
    AI 判斷是仿冒的列為 🔴；AI 判斷不是仿冒的不列燈號，但會列在報告的「AI 判斷不是仿冒的網站（請你確認）」，因為 AI 也可能判斷錯
    AI 的判斷存在 `data/cache/lookalike_verdicts.json`，同一個網站之後直接沿用，每次的報告才會一樣；想重新判斷就刪掉這個檔案
  - 完全不用 AI（`--llm none`）時，仿冒網域偵測照樣會找出可疑的網站，只是沒有 AI 幫忙分辨官方分站和仿冒，全部列 🟡 請你自己確認
  - 想補充店名：複製 `templates/165_shops.csv` 到個人資料資料夾，在最後面加一行（只填 `shop_name` 也可以）
  - 離線時加 `--no-165-fetch`，只用手動清單（把 `templates/165_shops.csv` 複製過去就能離線比對）
  - 更新範本裡的快照：`python -m stages.shops165 templates/165_shops.csv`

## Gmail 寄件者掃描

讀出所有信的**寄件者**，按網站整理成候選清單，再由 AI 和規則**自動判斷**哪些是帳號、還有沒有在用。
你只要看 AI 拿不準、標 ★ 的那幾列。只讀信件標頭，讀不到信件內容。

### 第一次使用：Google Cloud 設定（約 15～20 分鐘，只做一次）

> 介面名稱可能因 Google 改版略有不同。

1. 打開 <https://console.cloud.google.com/>，用**你要掃描的 Gmail 帳號**登入
2. 上方「選取專案」→「新增專案」→ 名稱填 `privacy-checkup` → 建立，並切換到這個專案
3. 啟用 Gmail API：打開 <https://console.cloud.google.com/apis/library/gmail.googleapis.com> → 按「啟用」
4. 左側選單找「**Google Auth Platform**」（舊版介面叫「OAuth 同意畫面」）→「開始」
   - 應用程式名稱：`privacy-checkup`；使用者支援電子郵件：你的 Gmail
   - 目標對象：**外部**
   - 聯絡資訊：你的 Gmail → 勾選同意 → 建立
5. 「**目標對象**」→「測試使用者」→「新增使用者」→ 填你的 Gmail → 儲存
   - 應用程式維持「測試中」就好，**不需要送審**
6. 「**用戶端**」→「建立用戶端」→ 應用程式類型選「**電腦版應用程式**」→ 建立 → **下載 JSON**
7. 把下載的檔案改名成 `gmail_credentials.json`，放進個人資料資料夾（還沒有這個資料夾的話，先執行一次 `python gmail_scan.py`，它會建立資料夾並印出位置）

### 執行

```powershell
python gmail_scan.py --limit 200   # 先掃最新 200 封試試看
python gmail_scan.py               # 掃整個信箱（1 萬封大約 5 分鐘）
```

1. 瀏覽器會開啟 Google 登入頁。看到「**Google 尚未驗證這個應用程式**」是正常的（這是你自己建的），按「繼續」
2. 權限頁面應該**只**寫「查看電子郵件訊息中繼資料，例如標籤和標頭，但不包括電子郵件內文」。看到其他權限就不要同意
3. 掃完會自動判斷，並印出結果，例如：
   ```
   自動判斷：還在用 25 個、不用了 18 個、不是帳號 60 個（AI＋規則都同意才自動填）
   ★ 要你確認：6 個（已經排在最前面）
   （沒有 AI 的話，要你確認的會是 31 個）
   ```
4. 會問你要不要撤銷授權（建議撤銷）
5. 打開個人資料資料夾裡的 `gmail_candidates.csv`（可以用 Excel）：
   - **只要看最前面標 ★ 的列**：參考 `suggested`（AI 傾向的答案）和 `reason`（理由），在 `still_using` 填 `y` 或 `n`
   - 其他列已經自動填好；`site_info` 是 AI 寫的「這是什麼網站」，`is_account` 是 AI 判斷是不是帳號
   - 自動填的答案不對，直接改就好
   - 不是帳號的留空，主程式會忽略；★ 列還沒填，也會先納入健檢

**怎麼自動判斷的（兩把鑰匙）**
- 規則看日期：最近一年還有登入、安全通知或訂單信 → 還在用；兩年以上沒收到信、三年以上沒有登入或訂單信 → 可能不用了
- AI 看寄件者和網站類型：例如論壇、遊戲網站平常不寄信，沒有來信不代表沒在用
- **兩邊都同意才自動填**，意見不同或沒把握的標 ★ 給你確認
- 例外：最近一年有登入、安全通知或訂單信的網站，規則已經能確定還在用，直接填 `y`，**不送給 AI**。
  這些是你最常用的帳號，AI 的意見也改變不了結果，就沒有必要讓它看到
- 你填過、改過的答案永遠保留，重新掃描也不會被蓋掉
- 送給 AI 的只有：網域、寄件者名稱、信件數、日期、標籤。主旨和內容不送；看起來像人名的寄件者名稱（例如「陳老師」）也不送
- 不想用 AI：加 `--llm none`，只用規則，要你確認的會比較多
- 已經掃過、想重新判斷（例如換一個 AI）：`python gmail_scan.py --retriage`，不用重新登入 Gmail

掃描別的帳號（例如示範帳號）時加 `--profile`，檔案才不會互相覆蓋：

```powershell
python gmail_scan.py --profile demo --no-browser   # 存成個人資料資料夾裡的 gmail_candidates_demo.csv
python main.py --demo --gmail "$HOME/privacy-checkup-secrets/gmail_candidates_demo.csv"
```

`--no-browser` 會印出登入網址，讓你貼到指定的瀏覽器視窗。都處理完後，可以到 Google Cloud 把 `privacy-checkup` 專案刪掉。

## 選擇 AI（`--llm`）

| 選項 | 用的是 | 需要準備 |
|---|---|---|
| `auto`（預設） | 自動找，依序是 Claude Code → Codex → Gemini 金鑰，用第一個**裝好而且登入了**的；都沒有就不用 AI | 不用設定 |
| `claude` | Claude Code CLI | Claude 訂閱。程式會自動找 `claude` 指令或 VS Code 擴充套件內附的執行檔；找不到時設定環境變數 `CLAUDE_BIN` |
| `codex` | OpenAI Codex CLI | ChatGPT 帳號（方案是否包含 Codex 以 OpenAI 公告為準）。安裝：`npm install -g @openai/codex`，再執行一次 `codex login`；也可以用 VS Code 的 Codex 擴充套件內附的執行檔；找不到時設定環境變數 `CODEX_BIN` |
| `gemini` | Google Gemini API | 免費的 API 金鑰（見下方） |
| `none` | 不使用 AI | 不用準備 |

- 自動偵測會跳過裝了但還沒登入的 AI，並印出怎麼登入；第一次呼叫就失敗（例如方案不含 Codex、額度用完）也會自動換下一個再試。成功過一次之後就固定用它，不會中途換
- 用 `--llm` 指定的話就只用那一個，不會自動換；它沒登入時，每一步都會印出「AI 呼叫失敗，改用規則判斷」，報告照樣產生
- 同時有好幾種的話，想用哪一個就用 `--llm` 指定
- `--model` 可以指定模型，例如 `--llm claude --model sonnet`

**申請 Gemini API 金鑰（免費）**
1. 打開 <https://aistudio.google.com/apikey>，用 Google 帳號登入，按「建立 API 金鑰」
2. 把金鑰存到個人資料資料夾，檔名 `gemini_api_key.txt`（只有一行），或在 PowerShell 設定：`$env:GEMINI_API_KEY="你的金鑰"`
3. 執行 `python main.py --demo --llm gemini`

- 免費方案有次數限制，用完會改用規則判斷，報告照樣產生
- 免費方案送出的內容可能會被 Google 用來改善產品；這個專案送出的只有網域、次數、日期這類資料，介意的話用 `--llm none`

## AI 看得到什麼

密碼、帳號名稱、email、你的備註、信件主旨，**在任何一步都不會送給 AI**。但 AI 要幫忙判斷，就一定看得到一部分的網域：

| 步驟 | 送給 AI 的內容 | 你的帳號網域會送出嗎 |
|---|---|---|
| Gmail 寄件者判斷（`gmail_scan.py`） | 寄件網站的網域、寄件者名稱（像人名的不送）、信件數、日期、標籤 | **會，而且最多**：寄過信給你的網站裡，規則還不能確定「還在用」的全部都送，範圍比帳號清單還大 |
| 辨認網站 | 網域、網站名稱 | 只有你標 `?` 的，和標記不再使用的 |
| 165 店名翻成網域 | 165 公布的店名 | **不會**（表上沒有的新店名才會問，問的也只有公開的店名） |
| 仿冒網域判斷 | 可疑的網址、它像的那家店名和官方網域 | 只有名稱很像官方網域的那幾個 |
| 寫白話說明（AI-2） | 外洩次數、外洩日期、外洩的資料種類、最早來信日期 | **不會**：網域、店名、事件名稱都換成代號（`[網站1]`、`[名稱2]`），AI 寫完再由程式換回來 |
| 寫總結（AI-3） | 燈號、要做的事 | **不會**：一樣用代號 |
| AI 調查員（`--agent`，預設關閉） | 全部帳號的網域和問題清單，加上工具查到的內容 | 全部 |

- 代號擋得住「直接看到網站名稱」，擋不住推測：外洩日期和資料種類還是會送出，很有名的外洩事件有可能被猜出來
- 每次的報告最後都有一節「這次送給 AI 的資料」，列出這次**實際**送了幾次、裡面有幾個你的帳號網域；完整內容在 `audit.log`
- 「你在哪些網站有帳號」本身也是個人資料。介意的話加 `--llm none`（`gmail_scan.py` 和 `main.py` 都可以加），
  全部改用規則判斷：要你自己確認的項目會變多、說明文字比較制式、可疑的仿冒網域一律列 🟡，但密碼和外洩事件的檢查結果、燈號都一樣
- 用訂閱方案的 Claude Code、Codex，或免費的 Gemini 金鑰時，送出的內容會不會被拿去改善產品，以各家的設定和條款為準

## AI 調查員（實驗功能，預設關閉）

加上 `--agent`，程式做完基本檢查後，會讓 AI 自己用 6 個唯讀工具追查：找名稱不一樣的外洩事件、補查 165 名單、追查紅燈項目的處理方法。
AI 的結論要引用查詢編號，程式檢查過依據才採用。報告最後會多一節「AI 調查紀錄」，列出 AI 查了什麼、採用和刪掉了哪些結論。

- 實測效益低（查 23 次沒有新發現），又會讓 AI 多看到一些資料，所以預設關閉
- 用 Claude 或 Codex 時需要先 `pip install mcp`，沒裝的話會提醒你並自動略過
- 這個功能的程式都放在 `experimental/` 資料夾。沒加 `--agent` 時，主程式完全不會載入它（有自我測試在檢查）；
  加了之後會多跑 4 個它自己的測試，而且一樣要過海關：白名單、敏感資料偵測、紀錄都和其他步驟共用同一個入口

## 接上你自己的 AI 工具（MCP，實驗功能）

想用平常習慣的 AI 工具聊自己的健檢結果，可以把 `experimental/mcp_server.py` 接上去。專案裡已經放好設定檔，
**用 AI 工具打開 `privacy-checkup` 這個資料夾就會自動偵測到**（第一次會問你要不要啟用）：

| 你用的工具 | 設定檔 | 怎麼確認有接上 |
|---|---|---|
| Claude Code | `.mcp.json` | 第一次開啟時選擇允許；輸入 `/mcp` 查看 |
| VS Code + GitHub Copilot | `.vscode/mcp.json` | Copilot 切到 Agent 模式，在工具清單裡找 `privacy-checkup` |
| Cursor | `.cursor/mcp.json` | 設定 → MCP |
| Codex CLI | 不能放在專案裡 | 執行一次：`codex mcp add privacy-checkup -- python "完整路徑\experimental\mcp_server.py"` |

1. 先跑完 `python main.py`（或 `--demo`），工具讀的是健檢結果
2. 問 AI，例如：「我的健檢結果哪些要先處理？」「幫我查 bnext 有沒有外洩紀錄」

⚠️ 個人資料資料夾已經不在專案裡，AI 工具打開專案時不會直接看到它。但這些工具有能力讀你電腦上其他位置的檔案，
所以**明文密碼檔（`passwords.csv`）還沒刪掉時，不要開 AI 工具**。

- 設定檔用的指令是 `python`；你的電腦要打 `py` 才能執行 Python 的話，請改設定檔裡的 `command`
- `python experimental/mcp_server.py` 是給 AI 工具啟動的，自己在終端機執行會停在那裡等待，按 Ctrl+C 結束
- 之前（舊版）用 `codex mcp add` 登記過的話，伺服器的位置從 `mcp_server.py` 搬到 `experimental/mcp_server.py` 了，要重新登記一次

## 之後想做的（Future work）

**主軸：持續監控。** 一般人是出事了才想到要檢查，所以與其要大家常常跑健檢，不如讓程式每天自己看一眼：
下載新的外洩事件，在本機和上次存下的帳號清單比對，有跟你有關的才通知。不需要密碼檔，大部分的日子也不需要 AI。
「和上次比」和固定編號就是為這件事準備的。每天要看的來源：

| 來源 | 補了什麼 |
|---|---|
| HIBP | 國際網站的外洩事件 |
| 165 高風險賣場名單 | 被詐騙集團冒名的台灣店家 |
| 上市櫃公司的資安重大訊息（證交所、櫃買中心 OpenAPI） | **台灣網站的外洩**，HIBP 幾乎查不到 |

最後一項是一次性健檢做不到的：上市櫃公司發生資安事件，依規定要用重大訊息第 26 款公告，
證交所和櫃買中心每天提供當天的公告（免金鑰），但**沒有歷史資料**，只能每天收、自己存起來。
例如 2026-11-11 櫻花和曜亞都發了公告：它們委外的電商平台廠商資料庫遭未經授權存取，購物商城會員的訂單和個人資料受影響。
出事的常常是委外的購物網站而不是公司本身，所以要讓 AI 讀公開的公告內容、找出網站和網域（做法和 165 店名對照一樣），
再在本機比對。公告多半寫「影響範圍釐清中」，所以列 🟡（提高防詐警覺、考慮換密碼）。

**其他想法**

- **讓 AI 看到更少**：Gmail 判斷改查一張公開的網站分類表（像 165 店名對照表那樣放在專案裡），或改用本機模型（例如 Ollama），
  連寄件網域都不用交給 AI。前者要先用標好答案的資料量過準確率；後者沒先做，是因為希望 clone 下來就能用，不要多裝東西
- **查到 email 這一層**：現在比對的是「這個網站出過事」，要知道「我的 email 在不在外洩資料裡」，
  得把 email 交給查詢服務（例如 HIBP 的付費金鑰），可以做成選用功能
- **密碼不落地**：Bitwarden、1Password 有官方指令可以把密碼直接交給程式，完全不產生密碼檔

## 程式架構（想檢查程式的話從哪裡看）

想確認「AI 到底拿得到什麼」，看前三個檔案就夠了：

| 位置 | 內容 |
|---|---|
| `guard.py` | 海關：整個程式唯一能呼叫 AI 的入口。`TASKS` 列出每一個會呼叫 AI 的工作，和它各自的白名單（只准送出哪些欄位）；沒登記的工作不能呼叫 AI |
| `llm.py` | 怎麼呼叫 Claude Code、Codex、Gemini：內建工具全部關掉、在空的資料夾裡執行 |
| `stages/ai_steps.py` | 給 AI 的每一段指示，和 AI 回覆之後的逐筆檢查 |
| `main.py` | 整個流程的順序 |
| `stages/` 其他檔案 | 不經過 AI 的部分：密碼檢查、帳號盤點、外洩比對、165 名單、仿冒網域、燈號規則（`findings.py`）、和上次比（`history.py`）、報告 |
| `gmail_scan.py`、`stages/gmail_triage.py` | Gmail 寄件者掃描和「兩把鑰匙」的判斷 |
| `common.py` | 共用工具：個人資料資料夾的位置、網域整理、下載快取 |
| `resources/` | 內附的公開資料：網域尾碼清單、165 店名對照表 |
| `tests/known_answers.py` | 自我測試 |
| `experimental/` | 實驗功能（AI 調查員、MCP 工具伺服器），預設不會載入 |

## 所有參數

**`python main.py`**

| 參數 | 用途 |
|---|---|
| `--demo` | 使用 `demo/` 裡的示範資料 |
| `--llm auto/claude/codex/gemini/none` | 選擇 AI（預設 `auto`：自動找電腦上有的） |
| `--agent` | 加上 AI 調查員（實驗功能，預設關閉） |
| `--model 名稱` | 指定模型 |
| `--passwords 檔案` | 已經匯出好的密碼檔（預設：個人資料資料夾的 `passwords.csv`）。建議不要先匯出，讓程式等你匯出、讀完馬上刪 |
| `--no-passwords` | 這次不檢查密碼，也不詢問；其他檢查照常 |
| `--manual 檔案` | 帳號清單（預設：個人資料資料夾的 `my_accounts.csv`） |
| `--gmail 檔案` | Gmail 候選清單（預設：個人資料資料夾的 `gmail_candidates.csv`） |
| `--shops 檔案` | 手動補充的 165 店名（預設：個人資料資料夾的 `165_shops.csv`） |
| `--no-165-fetch` | 不自動抓 165 名單，只用手動清單 |
| `--email 信箱 --holehe` | 用 holehe 查自己的 email |
| `--skip-tests` | 略過自我測試（不建議） |
| `--done 編號 …` | 把最近一次報告裡的項目標記成已處理，例如 `--done B1 T2`；不會執行健檢 |
| `--undo 編號 …` | 取消已處理的標記 |

**`python gmail_scan.py`**

| 參數 | 用途 |
|---|---|
| `--limit N` | 只掃最新的 N 封信 |
| `--profile 代號` | 不同帳號的檔案分開存，例如 `demo` |
| `--no-browser` | 不自動開瀏覽器，改成印出登入網址 |
| `--llm auto/claude/codex/gemini/none` | 幫忙判斷的 AI（預設 `auto`）；`none` 只用規則 |
| `--model 名稱` | 指定 AI 模型 |
| `--retriage` | 不重新掃描 Gmail，用現有的候選清單重新判斷 |
